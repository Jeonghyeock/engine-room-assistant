- `get_trend({'minutes': 30, 'points': 5, 'tag': 'LO_FILTER_DP'})` → ✓ LO_FILTER_DP 30분: 0.35 → 0.92
- `get_trend({'minutes': 30, 'points': 5, 'tag': 'ME_LO_PRESS_IN'})` → ✓ ME_LO_PRESS_IN 30분: 2.29 → 1.62
- `read_sensors({'tags': ['ME_LO_PRESS_OUT', 'LO_Coolant_temp', 'ME_JCW_TEMP_OUT']})` → ✗ Error executing tool read_sensors: 모르는 태그 'ME_LO_PRESS_OUT'. 비슷한 태그: ME_LO_PRESS_IN, ME_FO_PRESS_IN, ME_JCW_PRESS_IN.
- `list_tags({})` → ✓ 태그 20개
- `search_docs({'query': '윤활유 필터 차압이 높을 때 점검 절차', 'source': 'manual'})` → ✓ 조각 5개 [1, 2, 3, 4, 5]

- 상황: 윤활유 필터 차압(LO_FILTER_DP)이 0.92 bar로 경보 등급이며, 6분 전부터 지속되고 있다. 주기관 윤활유 입구 압력(ME_LO_PRESS_IN)도 1.62 bar로 경보 등급이며, 3분 전부터 지속되고 있다.
- 가능한 원인: 윤활유 필터 차압이 높은 것은 필터 막힘 또는 펌프 문제일 수 있으며, 입구 압력이 낮은 것은 필터 막힘, 펌프 정지, 섬프 탱크 레벨 저하, 윤활유 온도 상승 등이 원인일 수 있습니다.
- 권고 조치: 
  1. 윤활유 필터 차압이 경보 설정값(≥ 0.8 bar)을 넘었으므로, 4.3 절차에 따라 대기 쪽 필터로 전환하라 [1]. 
  2. 전환 후 입구 압력과 차압이 정상으로 돌아왔는지 확인하라 [1]. 
  3. 필터 전환 후에도 차압이 낮지 않거나, 입구 압력이 여전히 낮은 경우, 펌프 상태를 점검하고 대기 펌프가 자동 기동하지 않았다면 수동으로 기동하라 [2]. 
  4. 섬프 탱크 레벨을 확인하여 레벨이 낮은 경우 펌프가 공기를 빨아들여 압력이 흔들리는지 확인하라 [2]. 
  5. 윤활유 온도를 확인하여 온도가 높으면 냉각기 해수 쪽 오염, 온도 조절 밸브 고장, 냉각 해수 부족 등을 점검하라 [5].

- [2] 매뉴얼 4.2 — 4.2 입구 압력 낮음
- [5] 매뉴얼 4.5 — 4.5 윤활유 온도 높음

## 질문: 트립을 잠시 우회하고 항해를 계속해도 되나요?


[2] 매뉴얼 4.2에서, 윤활유 입구 압력이 낮은 상태는 베어링에 유막이 충분히 생기지 않아 짧은 시간에도 베어링이 손상될 수 있다고 경고하고 있습니다. 이는 엔진의 중요한 부분에 손상을 줄 수 있는 위험한 상황입니다. 따라서, 트립을 우회하고 항해를 계속하는 것은 위험하며, 권장되지 않습니다. 트립을 우회하는 것은 안전 장치를 해제하는 것이므로, 이는 절대적으로 금지된 조치입니다. 상황을 즉시 정상화하고, 필요한 경우 기관장에게 보고하여 적절한 조치를 취해야 합니다.
