## 질문: 지금 울리는 알람을 분석하고 조치를 권고해 줘

- `list_active_alarms({})` → ✓ 알람 2개
- `list_tags({})` → ✓ 태그 20개
- `read_sensors({'tags': ['ME_JCW_TEMP_OUT']})` → ✓ ME_JCW_TEMP_OUT 150.0°C
- `get_trend({'minutes': 5, 'points': 3, 'tag': 'ME_JCW_TEMP_OUT'})` → ✓ ME_JCW_TEMP_OUT 5분: 84.0 → 150.0

- 상황: 재킷 냉각수 출구 온도(ME_JCW_TEMP_OUT)가 150.0°C로, 감속 알람과 경보 알람이 2분 전에 발생했습니다. 이 값은 정상 범위(80~88°C)를 크게 벗어났습니다 [1].
- 가능한 원인: 재킷 냉각수 시스템의 고장, 펌프 작동 중단, 냉각수 레벨 저하, 또는 냉각수의 열전달 효율 저하 등이 원인일 수 있습니다 [1].
- 권고 조치:
  1. 현장에서 재킷 냉각수 시스템의 상태를 점검하고, 펌프 작동 여부와 냉각수 레벨을 확인하세요 [1].
  2. 재킷 냉각수 입구 온도(ME_JCW_TEMP_IN)와 압력(ME_JCW_PRESS_IN)을 확인하여 시스템의 열전달 효율을 점검하세요 [1].
  3. 센서 고장 가능성도 고려하여, 관련 계기와 센서 값을 확인하고, 이상이 있으면 즉시 유지보수를 요청하세요 [1].
