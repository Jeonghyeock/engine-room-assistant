## 질문: 지금 울리는 알람을 분석하고 조치를 권고해 줘

- `get_trend({'points': 10, 'tag': 'ME_LO_PRESS_IN', 'minutes': 30})` → ✓ ME_LO_PRESS_IN 30분: 2.29 → 1.62
- `list_tags({'system': 'LO'})` → ✓ 태그 6개
- `search_docs({'query': '윤활유 필터 차압이 떨어질 때 확인할 것', 'source': 'manual'})` → ✓ 조각 5개 [1, 2, 3, 4, 5]

- 상황: 윤활유 필터 차압(LO_FILTER_DP)이 0.92 bar로 경보 등급을 발령했고, 주기관 윤활유 입구 압력(ME_LO_PRESS_IN)이 1.62 bar로 경보 등급을 발령했다. 윤활유 필터 차압은 6분 전부터 점차 증가하고 있으며, 주기관 윤활유 입구 압력은 21분 전부터 서서히 감소하고 있다.
- 가능한 원인
  - 윤활유 필터 차압이 높아지면 필터가 막혔을 가능성이 있다 [1].
  - 주기관 윤활유 입구 압력이 감소하면 윤활유 펌프가 정지했거나, 윤활유 섬프 탱크 레벨이 낮아 공기를 빨아들일 수 있다 [1].
- 권고 조치:
  1. 윤활유 필터 차압이 경보 설정값(≥ 0.8)을 넘었으므로, 대기 쪽 필터로 전환하는 절차를 따르고, 공기빼기 밸브를 열어 대기 쪽 필터를 윤활유로 채운다 [2].
  2. 전환 밸브를 천천히 돌려 대기 쪽으로 전환한 후, 입구 압력과 차압이 정상으로 돌아왔는지 확인한다 [2].
  3. 막힌 쪽 필터를 열어 엘리먼트에 걸린 찌꺼기를 확인하고, 금속 입자가 많다면 기관장에게 보고하고 윤활유 시료를 분석한다 [2].
  4. 주기관 윤활유 입구 압력이 감소하고 있으므로, 펌프 상태를 확인하고 운전 펌프가 멈췄다면 대기 펌프를 수동으로 기동한다 [1].
  5. 윤활유 섬프 탱크 레벨을 확인하고, 레벨이 낮다면 펌프가 공기를 빨아들일 수 있으므로 레벨을 조정한다 [1].
  6. 윤활유 온도를 확인하고, 온도가 높으면 점도가 낮아 압력이 떨어질 수 있으므로 온도를 조절한다 [1].
  7. 원격 표시값과 현장 압력계를 비교해 계기 이상이 없는지 확인한다 [1].
